{# Anthropic settings #}
Don’t have a key yet? Here’s how — about 2 minutes:
  1. Open console.anthropic.com and sign in (or make a free account).
  2. Click Create Key, name it “Claw-ED,” and copy it.
  3. Paste it in the box above and click Save Settings. (It starts with sk-ant-.)
Get an Anthropic key → 🔒 Your key is stored only on this computer and is sent only to Anthropic to write your lessons — never to us. Anthropic is pay-as-you-go; a typical lesson costs only a few cents.
{# OpenAI settings #}
How to get an OpenAI key:
  1. Open platform.openai.com/api-keys and sign in.
  2. Click Create new secret key and copy it.
  3. Paste it above and click Save Settings. (It starts with sk-.)
Get an OpenAI key → 🔒 Stored only on this computer; sent only to OpenAI.
