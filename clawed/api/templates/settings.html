{# Anthropic settings #}
Don’t have a key yet? Here’s how — about 2 minutes:
  1. Open console.anthropic.com and sign in (or make a free account).
  2. Click Create Key, name it “Claw-ED,” and copy it.
  3. Paste it in the box above and click Save Settings. (It starts with sk-ant-.)
Get an Anthropic key → 🔒 Your key is stored only on this computer and is sent only to Anthropic to write your lessons — never to us. Anthropic is pay-as-you-go; a typical lesson costs only a few cents.
{# OpenAI settings #}
How to get an OpenAI key:
  1. Open platform.openai.com/api-keys and sign in.
  2. Click Create new secret key and copy it.
  3. Paste it above and click Save Settings. (It starts with sk-.)
Get an OpenAI key → 🔒 Stored only on this computer; sent only to OpenAI.

{# OpenRouter settings #}
One key, hundreds of models — including open-source & Chinese models:
  1. Open openrouter.ai/keys and sign in (or make a free account).
  2. Click Create Key, name it “Claw-ED,” and copy it.
  3. Paste it above, type a model slug in the box below, and click Save Settings. (It starts with sk-or-.)
Get an OpenRouter key → 🔒 Your key is stored only on this computer and is sent only to OpenRouter to write your lessons — never to us. OpenRouter routes to any model you name, so you can run open or Chinese models (e.g. DeepSeek, MiniMax, Qwen) at their pay-as-you-go rates.
Type any OpenRouter model slug — browse the full list at openrouter.ai/models. Examples: anthropic/claude-sonnet-4, deepseek/deepseek-chat, minimaxai/minimax-m1, qwen/qwen-2.5-72b-instruct.
{# Google (Gemini) settings #}
How to get a Google Gemini key — about 2 minutes:
  1. Open aistudio.google.com/apikey and sign in with your Google account.
  2. Click Create API key and copy it.
  3. Paste it above and click Save Settings. (It starts with AIza.)
Get a Google Gemini key → 🔒 Your key is stored only on this computer and is sent only to Google to write your lessons — never to us. Gemini offers a generous free tier plus low pay-as-you-go pricing.
