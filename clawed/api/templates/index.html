{# ----- Anthropic ----- #}
Don’t have a key yet? Here’s how — about 2 minutes:
  1. Open console.anthropic.com and sign in (or make a free account).
  2. Click Create Key, name it “Claw-ED,” and copy it.
  3. Paste it below and click Connect. (It starts with sk-ant-.)
Get an Anthropic key → {{ icon('lock', 14) }}Your key is stored only on this computer and is sent only to Anthropic to write your lessons — never to us. A typical lesson costs only a few cents.
Recommended: claude-sonnet-4-6 — great balance of quality and cost.
{# ----- OpenAI ----- #}
How to get an OpenAI key:
  1. Open platform.openai.com/api-keys and sign in.
  2. Click Create new secret key and copy it.
  3. Paste it below and click Connect. (It starts with sk-.)
Get an OpenAI key → {{ icon('lock', 14) }}Stored only on this computer; sent only to OpenAI.
Recommended: gpt-4.1. Cheaper option: gpt-4.1-mini.
{# ----- Ollama (no key) ----- #}
Ollama runs AI locally — free and private, no key needed.
  1. Install Ollama from ollama.com/download and open it.
  2. Pull a model in Terminal, e.g. ollama pull qwen3.5.
  3. Type that model name below and click Connect.
Get Ollama → {{ icon('lock', 14) }}Everything stays on your Mac — nothing is sent to the cloud.
Use the exact name you pulled (run ollama list to see them).
{# ----- OpenRouter ----- #}
One key, hundreds of models — including free & open ones:
  1. Open openrouter.ai/keys and sign in (or make a free account).
  2. Click Create Key, name it “Claw-ED,” and copy it.
  3. Paste it below and click Connect. (It starts with sk-or-.)
Get an OpenRouter key → {{ icon('lock', 14) }}Your key is stored only on this computer and is sent only to OpenRouter — never to us. Browse models at openrouter.ai/models.
Pre-filled with a free model. Prefer top quality? Try anthropic/claude-sonnet-4 (paid).
{# ----- Google Gemini ----- #}
How to get a Google Gemini key — about 2 minutes:
  1. Open aistudio.google.com/apikey and sign in with your Google account.
  2. Click Create API key and copy it.
  3. Paste it below and click Connect. (It starts with AIza.)
Get a Google Gemini key → {{ icon('lock', 14) }}Your key is stored only on this computer and is sent only to Google — never to us. Gemini has a generous free tier.
Recommended: gemini-2.5-flash (fast, free-tier friendly). Higher quality: gemini-2.5-pro.
